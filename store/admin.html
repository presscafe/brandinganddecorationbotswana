Import / Export — GitHub as the free CMS

All ERP data lives in IndexedDB (browser) — free, offline, durable. Use this panel to import supplier sheets and export JSON for GitHub (the durable, audited source of truth that Cloudflare Pages deploys). No paid DB needed.
