# SOP-09 — Defect, Rework and Credit-Note Handling

**Purpose:** rework ≤2%, resolved in 5 working days, root cause logged — not repeated.  
**Trigger:** any defect found at: first-article, in-process QC, partner receipt (SOP-06), or client complaint.  
**Owner:** Production lead. **Rev:** 29 Oct 2026. Metric: BDB-023 rework rate.

## Steps
1. **Quarantine:** tag defective units, separate, photo, count. Do not ship mixed batch.
2. **Log:** defect card in `admin.html → Certificates/Quotes` notes: `SKU | method | defect type (puckering, crack, misplacement, size mix, cure fail) | qty | discovered at | photo`.
3. **Root cause (5-whys, 15 min):** was it artwork, digitising, backing/pressure/temp, partner, or kitting? Assign cause, not blame.
4. **Correct:** remake at our cost if our defect; chargeable only if client-approved artwork error proven by signed proof (SOP-03). Rush remake gets priority lane.
5. **Close:** re-deliver with new packing list marked REMake. Client signs new POD. Log `days to resolve`.

## Quality gate
- [ ] Defect photo + count logged same day
- [ ] Root cause + corrective action documented
- [ ] Rework delivered ≤5 working days
- [ ] Credit note issued if agreed (finance signs)

## Non-negotiable
No defective units reach client after SOP-06 receipt QC. If they do, receipt QC failed — fix the checkpoint, not the person.
