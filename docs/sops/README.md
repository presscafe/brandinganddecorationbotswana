# SOP Library

Standard operating procedures live here, one file per SOP, named `SOP-01-quote-preparation.md` etc.
Each SOP records: **purpose · trigger · steps · quality gate · records · owner · revision date.**

The ten to write first (backlog item BDB-019). Nothing scales past the founder until these exist.

| # | SOP | Quality gate it protects |
|---|---|---|
| 01 | Quote preparation and validity rules | No quote leaves below the 28% decorated-work margin floor; duty, credit and delivery are priced, not absorbed |
| 02 | Artwork intake and Brand Vault update | Client logo files, pantones and size matrices are version-controlled from day one |
| 03 | Digitising and first-article approval | Colour, size, placement and stitch quality approved in writing before bulk runs |
| 04 | Embroidery production and QC | Consistent stitch density, backing and placement; waste and rework logged |
| 05 | DTF / screen production, curing and wash test | Print adhesion and durability verified, not assumed |
| 06 | Partner job issue, in-progress check and receipt QC | Partner work is inspected on receipt; defects never reach the client |
| 07 | Kitting, packing and packing-list generation | Correct items, correct sizes, correct count, labelled per recipient or site |
| 08 | Delivery, proof of delivery and installation sign-off | Every drop photographed and signed; disputes resolved by evidence |
| 09 | Defect, rework and credit-note handling | Rework ≤2%, resolved within 5 working days, root cause logged |
| 10 | Month-end: margin by job, partner scorecards, consumption reports, cash-cycle review | The business is managed on measured margin and cash, not on revenue vanity |

**Rule:** if a task has been performed three times the same way, it belongs here. If it is documented here and
still done from memory, the SOP is wrong — fix the SOP, not the person.
