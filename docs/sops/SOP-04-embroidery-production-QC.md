# SOP-04 — Embroidery production and QC

**Purpose:** consistent stitch density, backing and placement on every unit; waste and rework logged, not hidden.

**Trigger:** any embroidery job (in-house).

**Owner:** Machine operator. **Revision:** 2026-10-29 v1.

---

## 1. Pre-run (10 min)

1. Confirm job sheet: product, quantity, size breakdown, logo version, placement diagram, thread colours (by cone number), stitch count.
2. Load correct needles (75/11 ballpoint for knits, 80/12 for wovens/caps), bobbins, backing (see SOP-03), topping film if fleece.
3. Hoop test: one blank hooped, alignment checked with laser/needle point vs centre mark. Tension test — 5 cm satin column, no bobbin show.
4. Verify first-article is APPROVED (SOP-03) and its photo is on the job sheet.

## 2. Production

1. Run speed: piqué 700–850 spm, caps 600–700 spm, fleece 650 spm max. Do not chase speed at the cost of breaks.
2. Operator stays at machine for first 5 units; thereafter check every 10th unit for: placement, registration, thread breaks, trim tails.
3. Thread breaks >2 per 50 units → stop, re-tension, re-check digitising, log.

## 3. In-process QC (sample 1 in 20)

- [ ] Placement within ±3 mm of spec.
- [ ] No puckering, looping, or bird-nesting.
- [ ] Colours match cone map.
- [ ] Backing trimmed clean, no sharp edges (garment-facing).
- [ ] Size label still legible.

Defect found → tag the unit, set aside, log in rework sheet, correct before continuing.

## 4. End-of-run

1. Count by size, reconcile to job sheet. Any shortage → identify missing units before packing.
2. Remove topping film, trim jump threads, lint-roll.
3. Random pull: 3 units photographed (front + detail) for the job pack.
4. Log: units produced, units scrapped/reworked (by cause), machine time, thread cones consumed.

## 5. Housekeeping

- Oil and clean per machine manual (daily lint, weekly oiling). Log maintenance in `Equipment log`.
- Needles changed every 6–8 hours of run time or at any burr/skip.

## 6. Records

Job pack: job sheet + first-article approval + production count + defect log + 3 sample photos. Stored in `Drive: Clients/{Client}/Orders/{OrderNo}/`.

---

**Target:** rework ≤2%, throughput ≥50 productive minutes per hour.
