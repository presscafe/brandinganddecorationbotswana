# SOP-03 — Digitising and first-article approval

**Purpose:** colour, size, placement and stitch quality are proven on one unit and approved in writing before 99–499 more are produced. This is how a 500-unit defect becomes a 1-unit correction.

**Trigger:** any order >12 units with embroidery, or >48 units with screen print, or any first order for a new client/logo.

**Owner:** Production lead. **Revision:** 2026-10-29 v1.

---

## 1. Digitising standards

1. Only a trained digitiser edits stitch files. Keep the source (e.g. Wilcom/Embird) plus exported DST/EXP.
2. Settings by garment:
   - Golf shirt piqué: backing — tearaway + cut-away for dense logos; density 4.2–4.6 lines/mm; underlay — zigzag + edge walk.
   - Softshell/caps: cap driver, centre-out, speed ≤700 spm.
   - Fleece/hoodie: topping film (Solvy) to prevent sinking.
3. Thread: Madeira Polyneon or Isacord equivalent; colour map per Brand Vault (SOP-02). No substitution without client sign-off.
4. Stitch count recorded in the Brand Vault index and on the job sheet.

## 2. First-article production

1. Produce **one finished unit** on the exact blank that will be used for the bulk (same fabric, colour, batch if possible).
2. Measure: width × height (mm), placement from collar/centre/seam, stitch count, backing type.
3. Photograph: front full, close-up of logo (with ruler for scale), back label/size, thread cone colours in frame. Daylight, no filter.
4. Checks (tick each):
   - [ ] Dimensions within ±2 mm of proof.
   - [ ] Colour matches approved thread/Pantone under daylight.
   - [ ] No puckering, no registration shift, no thread breaks, no bobbin show-through.
   - [ ] Placement centred per spec (±3 mm).
   - [ ] Wash test planned? For new garment/thread combo, wash one article once at 40°C and re-inspect (log result).

## 3. Approval

1. Send to client: 2–3 photos + dimensions + “Reply ‘APPROVED’ to authorise bulk.”
2. For mine/corporate clients, copy the procurement contact + the wearer representative if available.
3. Store written approval in `Drive: Clients/{Client}/Orders/{OrderNo}/First Article/`.
4. **No bulk starts without written approval.** If client requests same-day bulk without approval, Director must authorise in writing and note “client waived first-article — risk accepted”.

## 4. Bulk run controls

1. First 10 units of bulk are inspected 100%; thereafter sample 1 in 20.
2. Any defect → stop, diagnose, correct, re-run first-article. Log defect type (see SOP-09).
3. End-of-run: count, size-breakdown verification, random pull of 3 units for final photo.

## 5. Partner-issued work

- If a partner digitises or embroiders, they must follow this SOP and supply the first-article photos + file before we approve their bulk. Our QC on receipt (SOP-06) is not a substitute for their first-article.

## 6. Records

- Job sheet + stitch file version + first-article photos + written approval + wash-test result (if done) + bulk sample photos = the job pack. Retained 12 months (24 months for programme clients).

---

**Red line:** a bulk defect that would have been caught by a first-article is a process failure, not bad luck. Investigate the SOP, not the person — then fix the SOP.
