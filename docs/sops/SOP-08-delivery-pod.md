# SOP-08 — Delivery, Proof of Delivery and Installation Sign-Off

**Purpose:** every drop photographed and signed; disputes resolved by evidence, not argument.  
**Trigger:** kitting complete, delivery scheduled.  
**Owner:** Operations/Driver. **Rev:** 29 Oct 2026.

## Steps
1. **Plan:** confirm delivery window + contact + access (gate, induction for mines). Choose courier vs own vehicle per `data/catalogue.json → delivery` fee table (free ≥P25k). Consolidate multi-site into one run where feasible (fuel stewardship).
2. **Dispatch:** driver carries: packing list ×2, POD form, phone for photos. ERP status → `out for delivery`.
3. **Drop:** at gate/reception: count cartons vs packing list with recipient, open one carton for spot-check, photo of: (a) cartons at drop, (b) POD signed, (c) installation if display/event (gazebo/banners erected).
4. **POD:** signature + name + date + time + any shortage/damage noted on the spot. No blank signature.
5. **Close:** status → `delivered` in ERP, upload POD photo + delivery photo, email POD PDF to client within 4h.

## Quality gate
- [ ] POD signed with no unresolved shortage
- [ ] Photos uploaded before invoicing
- [ ] Any shortage logged as rework (SOP-09) same day

## Records
POD + photos → ERP + Drive `/Jobs/{Ref}/Delivery`. Retention 2 years (mines) / 7 years (tax).
